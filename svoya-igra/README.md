# Своя игра: материалы для вечеринки

- [`paket-1.md`](paket-1.md) — пакет №1: 19 тем, в каждой 5 вопросов по 200, 400, 600, 800 и 1000 очков (всего 95 вопросов) с ответами.

## Как собрать игру из пакета

- **Один раунд** — 5–6 тем, то есть 25–30 вопросов. На 19 тем хватает на три раунда с запасом.
- **Номиналы** идут по возрастанию сложности: 200 — для разогрева, 1000 — на знатока.
- **Финал** можно сделать на одной из «разговорных» тем (например, «С каких вопросов раньше начинались драки» или «Чем мы только не закусывали»): игроки пишут ответ и ставку.
- **Кот в мешке** хорошо заходит на стыке тем: вопрос из «Фарцовщиков» отдать играющему «Союзмультфильм», и наоборот.
- **Вопрос-аукцион** логичнее ставить на 800 или 1000 в темах про 90-е.

## Правила приёма ответов

- Ответ принимается, если названо главное слово: фамилия без имени, название без года, марка без модели.
- В пакете у части вопросов явно указаны допустимые варианты — они равноценны основному ответу.
- В теме «Стиль или кринж» игрок обязан назвать сам предмет; вердикт «стиль или кринж» ведущий объявляет сам, это повод для спора с залом, а не часть ответа.
- Темы «Цитаты Ельцина или алкоголик» и «Смысл песен Бутусова» требуют дословных формулировок — ведущему стоит зачитывать ответ целиком, вместе с пояснением.
